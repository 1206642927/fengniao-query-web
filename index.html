怎么复制？看这里（30 秒）

1. 用 Edge/Chrome 打开并登录 riskbird.com，按 F12 → 切到「网络 / Network」标签，刷新一下页面；
2. 在请求列表里，随便点哪一条以 riskbird-api 开头的请求都行（例如列表最上面的 balance 或 recent-records?queryType=1 —— 它们带的登录凭证完全一样）；
3. 在这条请求上 点右键 → 选择「复制为 cURL (bash)」（右键菜单里的第 2 项；不要选 PowerShell / fetch 那些格式）；
4. 回到本页面，把复制到的整段内容粘贴到下面的框里 → 点「加密保存到仓库 Secret」。

提示：这一步永远只有管理员做（每隔几天~几周 Cookie 过期时一次）；其他使用者不需要也不应该接触这里。
