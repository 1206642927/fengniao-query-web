1连接设置（只需设置一次）

怎么创建 Token？（约2分钟）

GitHub → 右上角头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token：

① Repository access 选 “Only select repositories” → 勾选你的数据仓库（如 fengniao-query）；
② Permissions 里给：Contents → Read and write、Actions → Read and write、Secrets → Read and write（最后一项用于“一键更新Cookie”，可以不给）；
③ 生成后复制粘贴到上面。也可以使用经典令牌（Classic，勾选 repo 权限）。

2更新风鸟 Cookie（登录凭证，过期时用）

怎么获取风鸟 Cookie？

用 Edge/Chrome 打开并登录 riskbird.com → 按 F12 → 「网络/Network」→ 刷新页面 → 点任意一个 riskbird-api 开头的请求 → 右键 → 复制 → 以 cURL 格式复制 → 整段粘贴到上面的框里。
